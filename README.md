# KM Rodado

Sistema de gestão operacional para motoristas profissionais.

## Objetivo

O KM Rodado tem como objetivo auxiliar motoristas que utilizam veículos como ferramenta de trabalho no controle de:

- custos;
- receitas;
- manutenção;
- consumo;
- produtividade.

## Tecnologias

- Flutter
- Dart
- SQLite
- Git/GitHub
