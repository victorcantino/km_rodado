# Convenções de formulários

- A ordem visual segue o fluxo real de uso.
- `Next`/`Done` acompanham somente a ordem dos campos editáveis.
- Campos numéricos operacionais favorecem substituição rápida, com seleção
  integral no primeiro foco/toque quando aplicável.
- Usar defaults sensatos e autofocus somente quando ajudar.
- Data/hora deve ser compacta e editável sem interromper o fluxo principal.
- Autocomplete e histórico são preferíveis quando reduzem digitação repetida.
- Não criar botões auxiliares quando valores puderem ser derivados.
- Edição e exclusão seguem os padrões definidos para listas.
- Números, datas e moeda usam pt-BR e vírgula decimal.
